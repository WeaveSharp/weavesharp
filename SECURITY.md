# Security

## Reporting a vulnerability

Please report a suspected vulnerability privately, never in a public issue, discussion or pull request.

1. Use GitHub's private vulnerability reporting: on this repository's **Security** tab, choose **Report a vulnerability**.
2. If you cannot use GitHub, email weavesharp@jasonfurr.com with "Security" in the subject.

Include what you found, the WeaveSharp version and editor, and the steps that show the problem. You will get an acknowledgment and updates in the same private report. A fix is developed privately and described publicly when the release that carries it is published.

## What this covers

This repository and every released WeaveSharp extension: the VS Code extension, the Rider plugin and the Visual Studio extension, with their shared services. Nothing is released yet, so today this covers the repository's own code and workflows.

Problems in Visual Studio, VS Code, Rider, the .NET SDK, a debugger or another vendor's extension belong to that vendor. If you are unsure, report it here privately and we will route it.
